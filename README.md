# InitialRepo

Initial development environment setup for working with Cursor, Git, and GitHub.

## Tools Installed

| Tool | Purpose |
|------|---------|
| **Cursor** | AI-powered code editor used as the primary development environment |
| **Git** | Version control for tracking changes and collaborating via GitHub |
| **GitHub** | Remote repository hosting and account for pushing and pulling code |
| **Claude Code extension** | Cursor extension for AI-assisted coding with Claude |
| **Codex extension** | Cursor extension for AI-assisted coding with OpenAI Codex |

## Setup Steps Completed

1. **Installed and configured Cursor** — Set up the Cursor IDE as the main editor for this project.

2. **Created a GitHub account** — Registered and signed in to GitHub for remote repository access.

3. **Initialized and linked the Git repository** — Connected this local project to the remote repository at [github.com/svaragehlot/InitialRepo](https://github.com/svaragehlot/InitialRepo).

4. **Linked GitHub with Cursor** — Authenticated and connected the GitHub account inside Cursor so commits, pushes, and pulls work from the editor.

5. **Installed Cursor extensions** — Added the **Claude Code** and **Codex** extensions from the Cursor marketplace to enable AI-assisted development workflows.

6. **Verified the setup** — Confirmed the repository is on the `main` branch, tracking `origin/main`, with a clean working tree.

## Issues Encountered and Solutions

No major blockers occurred during setup. The main work was routine first-time configuration:

| Issue | Solution |
|-------|----------|
| GitHub account needed to be linked with Cursor | Signed in to GitHub through Cursor’s account settings and authorized the connection so Git operations (push, pull, clone) work seamlessly from the IDE. |
| Initial Git remote setup | Added the GitHub repository as the `origin` remote and verified the link with `git remote -v`. |
